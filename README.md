# GI Heritage Hub 🇮🇳

> **🤖 AI SUCCESSOR DIRECTIVE:** If you are an AI agent taking over this project, begin by reading `docs/AI_HANDOVER.md` and `docs/AI_BRAIN_HANDOVER.md`. These files contain the full architectural context, logic patterns, and the "mental model" of the creator AI.

A verified marketplace for authentic Indian handcrafted goods, focusing on Geographical Indication (GI) tags and artisan storytelling.

## 🌟 The Vision
GI Heritage Hub solves three core problems:
1. **Authenticity:** Only GI-tagged and verified artisans can sell, ensuring cultural preservation.
2. **Language:** Real-time AI translation removes barriers between rural artisans and global buyers.
3. **Heritage:** AI-assisted narratives transform raw crafts into powerful cultural stories.

## 🏗 Technical Stack
- **Framework:** Next.js 15 (App Router).
- **Backend:** Firebase (Auth, Firestore).
- **AI Engine:** Genkit + Gemini 2.5 Flash.
- **Styling:** Tailwind CSS + ShadCN UI + Alegreya Serif Typography.

## 🛠 Setup & Migration
1. **Clone & Install:** `npm install`
2. **Environment:** Copy `.env.example` to `.env`. Populate with your Firebase & Gemini keys.
3. **Run:** `npm run dev`
4. **Deploy:** Optimized for Antigravity, Cloudflare Pages, or Firebase App Hosting.

## 📍 Status: Demo-Ready
This application uses a **Hybrid-Resilient Engine**. It gracefully merges live Firestore data with curated local mocks, ensuring the marketplace is always vibrant even if the backend is disconnected.
